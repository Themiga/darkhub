Built for Security

Every layer is hardened against bypass, spoofing and source theft.

🔐

AES-GCM at Rest

All scripts are stored AES-256-GCM encrypted in the database. Plaintext never touches disk.

🔑

Per-Request XOR Key

Each loader request generates a unique HMAC-derived XOR keystream. Captured traffic is useless.

🛡️

One-Time Nonces

Every request nonce is consumed immediately. Replay attacks are blocked at the server level.

📊

Server-Side Analytics

Execution counts tracked entirely server-side. Zero code injected into your scripts.

⚡

Anti-Dump Hooks

The Hub overrides writefile, getscriptbytecode and similar APIs before executing your code.

🚫

Rate Limiting

IP-based rate limiting on all endpoints. Scraping and brute-force attempts are dropped instantly.

One-Line Loader

Paste this into any Roblox exploit executor. The Hub automatically detects your game and loads the right script — or aborts cleanly if unsupported. 

loadstring(game:HttpGet("https://YOUR-WORKER.workers.dev/hub"))();

⚠️ Replace YOUR-WORKER.workers.dev with your actual Cloudflare Worker URL after deploy.
